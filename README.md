# 🎮 Multi-Game Hub

A fun and interactive web application that brings multiple games together on a single platform. Instead of visiting different websites to play different games, users can access and enjoy multiple games through one unified interface.

## 🚀 About the Project

Multi-Game Hub is a web-based gaming platform designed to provide users with an easy and engaging gaming experience. It combines multiple individual games into one website with a common dashboard and simple navigation.

The platform focuses on clean UI, responsive design, and smooth interaction between different games.

## ✨ Features

- 🎯 Multiple games available on a single website.
- 🏠 Centralized dashboard for accessing games.
- 🎨 Interactive and user-friendly interface.
- 📱 Responsive design for desktop and mobile devices.
- ⚡ Smooth navigation between different games.
- 🧩 Modular and reusable component structure.

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/your-username/your-repository.git
```

2. Navigate to the project directory:

```bash
cd your-repository
```

3. Install frontend dependencies:

```bash
cd frontend
npm install
```

4. Start the frontend:

```bash
npm run dev
```

5. If your project has a separate backend, open another terminal:

